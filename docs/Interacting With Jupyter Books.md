## 🪐 Working with Jupyter Books

Two types of documents are utilized across this and other chapters to deliver content and code:

### 📄 1. Markdown Documents (.md)
* **What it is:** Static text (like what you are currently reading).  
* **Code:** Contains no executable code.  
* **Downloads:** Available to save as a Markdown (`.md`) or PDF (`.pdf`) file.

### 🧑‍💻 2. Notebook Documents (.ipynb)
* **What it is:** Interactive documents combining narrative text with live Python code.  
* **Code:** Fully interactive. You can run code directly on the page or open it in a dedicated cloud environment.  
* **Downloads:** Available to save as a Jupyter Notebook (`.ipynb`) or PDF (`.pdf`) file.

---

## 🚀 Notebook Launch Options

For `.ipynb` files, you have three ways to interact with the code:

* **Run Live Code:** Click the **Live Code** (rocket icon) at the top of a notebook page to execute code directly inside the book. *Note: This relies on a free, public Binder server. It can take a moment to load and is limited to 100 concurrent users from the same repository.*
* **Quick Launch:** The first cell in every notebook includes direct links to open the environment in **Colab** or **Binder**.  
  * **Colab:** Requires a free Google account, but is fast and seamless.  
  * **Binder:** No account required, but has the same loading times and limits as the Live Code option.
* **Download:** The notebooks can be downloaded to your computer and run locally using JupyterLab or VS Code.  

> **💡 Pro-Tip:** Hover over the upper-right corner of any code cell or block to reveal a clipboard icon for **One-Click Copying**.
